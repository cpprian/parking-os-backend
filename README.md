# Parking OS Backend

## Overview

This repository contains the backend services for the Parking OS application, which provides a comprehensive solution for managing parking spaces, user accounts, and payment processing.

## Features

- User authentication and authorization
- Parking space management
- Real-time parking availability updates
- Tariff management
- API documentation, OpenAPI/Swagger

## Technologies Used

- Rust
- Axum framework
- MongoDB for NoSQL storage
- JWT for authentication
- Docker for containerization
